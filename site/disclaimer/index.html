Provided as is. It spends your money, runs code a model wrote, and its agents make mistakes.

It spends your money. HypSwarm runs AI agents with the model provider and key you give it. Every call is billed to you by that provider, at that provider's prices. A run's budget (calls, dollars) is enforced by HypSwarm's own count of tokens and prices, which can differ from what the provider bills; treat it as a limit that is best effort, not a guarantee, and set a spending cap with your provider too.

It runs code a model wrote. Seats can write and run code. The default sandbox is a subprocess with a time limit on your machine: it runs as you, with your files and your network. It is not a security boundary. Run untrusted work in a sandbox you trust, such as a container or HypDMZ.

Agents make mistakes. The record refuses some overclaims as they are written, and standing is derived, not certified (see the HypGraph disclaimer). A swarm's claims, reports and code can still be wrong. Check what they say before you act on it. Nothing a swarm produces is legal, medical, financial or investment advice; the trading profile works on paper positions and historical data.
