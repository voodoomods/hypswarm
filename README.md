<h1 align="center">hypswarm</h1>
<p align="center"><b>Many agents. One record.</b><br>
Run one agent or a swarm of them on a research or building task, with a <a href="https://hypgraph.com">HypGraph</a>
record as the only shared state.<br>
<a href="https://hypswarm.com">hypswarm.com</a> · <a href="https://github.com/voodoomods/hypswarm">source</a> ·
<a href="https://hypgraph.com">HypGraph</a></p>

---

**This release reserves the name.** The alpha — the scheduler, workers, external seats over MCP, the record server
mode, the OpenAI-compatible and Anthropic adapters — lives on [GitHub](https://github.com/voodoomods/hypswarm) and
installs from there until HypGraph's coordination layer is on PyPI:

```bash
pip install "hypgraph @ git+https://github.com/voodoomods/hypgraph@harmony-study"
pip install git+https://github.com/voodoomods/hypswarm
```
